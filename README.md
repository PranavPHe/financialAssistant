# FINANCIAL ASSISTANT

## Purpose
The purpose of this program is for companies to be able to manage their financial records, such as seeing their latest, most expensive, or least expensive expense. The program is meant to make storing company financial records an easier process.


## Run
```
./run.ps1 //(For Windows)
OR
./run.sh //(For Linux)
```

## Features
- Saving Financial Records
- Updating expenses
- Updating budgets
- Analytics related to budgets/expenses
